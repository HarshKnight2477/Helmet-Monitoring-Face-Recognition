# Model weights

Download `helmet_yolov8.pt` from the [latest release](https://github.com/HarshKnight2477/Helmet-Monitoring-Face-Recognition/releases/latest) and place it here.

To train it yourself, use [`training/helmet_yolov8_kaggle.ipynb`](../training/helmet_yolov8_kaggle.ipynb) on Kaggle, or follow the local GPU steps in the main README.

The InsightFace face model (`buffalo_l`) downloads automatically to `~/.insightface` on first start.
