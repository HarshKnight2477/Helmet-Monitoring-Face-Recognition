# Model weights

Put the trained helmet detector here as `helmet_yolov8.pt`.

Train it with [`training/helmet_yolov8_kaggle.ipynb`](../training/helmet_yolov8_kaggle.ipynb) on Kaggle (free GPU), then download `helmet_yolov8.pt` from the notebook's Output tab.

The InsightFace face model (`buffalo_l`) downloads automatically to `~/.insightface` on first start.
